# 📄 Resume Screening System

## Overview

The Resume Screening System is an AI-powered recruitment assistant developed using Python and Streamlit. The application helps recruiters evaluate candidates by comparing their skills, education, and experience against specific job role requirements.

The system automatically calculates a match score, identifies missing skills, ranks candidates, and generates hiring recommendations, making the recruitment process faster and more efficient.

## How It Works

1. Enter candidate information.
2. Select the target job role.
3. Enter candidate skills.
4. Provide experience and education details.
5. The system evaluates the profile.
6. Match score and ranking are generated.
7. Missing skills are identified.
8. Hiring recommendations are displayed.
